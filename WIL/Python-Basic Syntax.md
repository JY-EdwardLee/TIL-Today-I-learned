### 표현식과 값

- **표현식**이 **평가**되어 값이 **반환**(return)됨
    - 표현식 : 값으로 평가될 수 있는 코드 조각 (e.g. 3 + 5)
    - 평가 : 표현식을 실행하여 값을 얻는 과정
        
        ⇒ 표현식을 순차적으로 평가하여 어떤 동작을 할 지 결정
        
- 문장
    - 여러개의 표현식을 합침
- 타입
    - 정의 : 변수나 값이 가질 수 있는 데이터의 종류
        
        ⇒ 어떤 종류의 데이터인지, 어떻게 해석되고 처리되어야 하는지를 정의
        
    - 중요성 : 타입에 맞는 연산을 수행할 수 있음
        
        (타입마다 가능한 연산이 다름)
- 변수 할당
    
    : 표현식을 통해 변수에 값을 저장
    
    *= : 할당연산자
    
- 변수에 메모리 주소값을 가지게 되고 → 이 주소값을 참조하여 해당 값을 인식
    
    → 변수 : 값을 참조(저장 X)하기 위한 이름

- Numeric Type
    1. int (정수 자료형)
        - 진수 표현 : 접두어 붙음
            - 2진수 : 0b, 8진수 : 0o, 16진수 : 0x
    2. float (실수 자료형, 부동소수점)
        - 지수 표현 : e or E를 사용
            
            e.g. number = 314e-2 (← 314*0.1)
            
        - 프로그래밍 언어에서 float는 실수에 대한 **근삿값**
            - 컴퓨터 메모리의 유한성으로 인해, 가장 가까운 값으로 저장
        
        ※부동소수점 에러
        
        : 실수를 2진수로 변환하는 가정에서 발생하는 근사치 표현 ⇒ 오차 발생
        
        Decimal 함수를 사용해서 오차 제거 가능
        
- Sequence Types

|Type|	속성|	특징|
| ---|---|---|
|list|	가변|	|
|tuple|	불변|	개발자가 사용할 일은 없음|
|range|	불변|	|

  - 특징
      1. 순서 : 순서대로 저장 (정렬X)
       2. 인덱싱 : 각 값에 고유한 인덱스(번호)를 가짐, 인덱스 사용하여 특정 위치의 값을 선택하거나 수정 (인덱스는 0부터 시작)
       3. 슬라이싱 : 인덱스 범위를 조절해 부분적인 값을 추출할 수 있음
       4. 길이 : len() 함수를 사용하여 저장된 값의 개수(길이) 구할 수 있음
       5. 반복(iteration) : 반복문을 사용하여 저장된 값들을 반복적으로 처리할 수 있음
    
  - str : 문자들의 순서가 있는 변경 불가능한 시퀀스 자료형
       - 큰 따옴표 또는 작은 따옴표로 감싸서 표현
           - sequence escape

   - string interpolation
       - 문자열 변수 삽입

           : f 접두어를 붙이고 {expression}로 작성하는 문법
           
           ※ 중괄호를 안에 넣고 싶으면 {{}}
            
           ※ formating : print(’{}~~{}~~{}’.format(변수, 변수, 변수)
            
   - 인덱스

  | str | E | L | F |
  | --- | --- | --- | --- |
  | index | 0 | 1 | 2 |
  | index | -3 | -2 | -1 |
   - 슬라이싱
     - [시작:끝:setp] : 시작 ~ 끝 전까지지

- List
    
    **: “가변”**적인 시퀀스 자료형 (문자열은 불변)
    
    - 리스트 표현법 : []
        - 어떠한 데이터 자료형도 저장 가능 (List안에 List 저장 가능)
- tuple
    
    : 0개 이상의 객체를 포함한 데이터 목록을 저장 (불변)
    
    ※ 리스트와의 차이점 : 가변 vs 불변
    
    - 튜플 표현법 : ()
    - 튜플 사용되는 경우
        
        : 내부 동작과 안전한 데이터 전달에 사용됨 (개발자가 의도적으로 쓰지는 않음)
        
        e.g. RGM, 좌표
        
        ※ 튜플이 활용되는 특징 : 다중 할당, 값 교환, 그룹화(언패킹)
        
- range
    
    : 연속된 정수 시퀀스를 생성하는 변경 불가능한 자료형 
    
    - range 표현법 : range(시작 값(n), 끝 값(m), 증가 값=step)
        - n부터 m-1까지 증가
    - 형 변환을 통해서 확인 가

### non-sequence Types

| Type | **속성** | **특징** |
| --- | --- | --- |
| dict | key : 불변, 중복/순서 없음
value : 가변, 중복 가능 | key-value 쌍으로 이루어짐 |
| set | 불변
중복/순서 없음 | 집합 연산 외에는 쓸 일 없음 |
- dict
    
    : **key-value 쌍**으로 이루어진 **순서**와 **중복이 없는 변경 가능**한 자료형
    
    - 딕셔너리 표현법 : {’key’ : ‘value’}
        - key : 변경 불가능한 자료형만 가능 (str, int, float, tuple, range, …)
        - value : 모든 자료형 가능
    - why dict?
        - 데이터를 정의하고 탐색하기 위해서
            
            ※ list는 데이터의 설명을 추가할 수 있고, 선형적 탐색만 가능
            
        - dict는 순서가 없어서 각 데이터의 순서로 정의할 수 없음
        - key는 중복 불가능 (value는 중복 가능)
- set (집합 자료형)
    
    : 순서와 중복이 없는 **변경 가능한** 자료형
    
    - 세트 표현법 : set() ← 빈 세트, {데이터}
    - 집합 연산 가능
        - | : 합집합, - : 차집합, & ; 교집합

### 기타

- None
    
    : 파이썬에서 ‘값이 없음’을 표현하는 자료형
    
    - None 표현법 : = None (’N’ 대문자로)
- Boolean
    
    : 참(True)과 거짓(False)을 표현하는 자료형
    
    - boolean 표혀법 : =True, = False

### Collection

- 여러 개의 항목 또는 요소를 담는 자료 구조 (#collection)

| **컬렉션** | **변경 가능 여부** | **순서 여부** |
| --- | --- | --- |
| **str** | X | O |
| **list** | O | O |
| **tuple** | X | O |
| **dict** | O (value만) | X |
| **set** | O | X |
- 불변과 가변의 차이
    - 불변인 친구는 : object 자체가 하나의 메모리 주소를 가져감
    - 가변인 친구는 : 각 방에 하나씩 메모리 주소를 모아놓은 집 형식
