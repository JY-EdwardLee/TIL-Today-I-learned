### Memoization (메모이제이션)

- Why Memoization?
    - 피보나치를 예로 들어보자,
    10까지 피보나치 수열을 재귀함수로 구현해 보면 177번의 호출이 발생한다.
        
        ![image.png](attachment:d256ec10-a3b6-4cbf-93f5-aced190333dc:image.png)
        
- 이전에 **계산한 값을 메모리에 저장**해서 매번 다시 계산하지 않도록 하여 **실행 속도 개선**
    
    ⇒ 동적 계획법의 핵심
    
- ‘메모리에 넣기(to put into memory)’ (※ memorization 아님 주의)
    
    e.g. 피보나치
    
    - 피보나치에서 fibo(n) 값을 계산 후 저장하면 → 실행시간 O(n) 구현 가능
        
        ```python
        # memo를 위한 배열을 할당하고, 모두 0으로 초기화
        # memo[0]을 0으로 memo[1]는 1로 초기화
        
        def fibo1(n):
            global cnt
            cnt += 1
            if n >= 2 and memo[n] == 0:  # 현재 메모[상위]는 0 일 것이니 저장이 안되어 있음
                memo[n] = fibo1(n - 1) + fibo1(n - 2)
            return memo[n]
        
        n = 10
        cnt = 0
        memo = [0] * (n + 1)
        memo[0] = 0
        memo[1] = 1
        print(fibo1(n), cnt)
        ```
        

### DP(Dynamic Programming)

- 그리디 알고리즘과 같이 **최적화 문제**를 해결하는 알고리즘이다.
- 입력 크기가 작은 부분 → 입력 크기가 큰 부분 순으로 해결
    
    → 최종적으로 원래 주어진 입력의 문제를 해결하는 알고리즘
    
- 피보나치 수 DP 적용
    1. 문제를 부분 문제로 분할하기
        
        fibo(1)은 fibo(n-1)과 fibo(n-2)의 합
        
        fibo(n-1)은 fibo(n-2)와 fibo(n-3)의 합
        
        fibo(2)는 fibo(1)과 fibo(0)의 합
        
        fibo(n)은 fibo(n-1), fibo(n-2), … fibo(1), fibo(0)의 최적 부분 구조로 나뉜다.
        
    2. 부분 문제로 나누는 일을 끝냈으면 가장 작은 부분 문제부터 해를 구한다.
    3. 그 결과는 테이블에 저장하고, 테이블에 저장된 부분 문제의 해를 이용하여 상위 문제의 해를 구함
        
        
        | 테이블 인덱스 | 저장되어 있는 값 |
        | --- | --- |
        | [0] | 0 |
        | [1] | 1 |
        | [2] | 1 |
        | [3] | 2 |
        | … | … |
        | [n] | fibo(n) |
    
    ⇒ 적용 알고리즘
    
    ```python
    def fibo2(n):
        f = [0]*(n+1)
        f[0] = 0
        f[1] = 1
        for i in range(2, n+1):
            f[i] = f[i-1] + f[i-2]
    
        return f[n]
    ```
    
- DP의 구현 방식
    - recursiv 방식 : 하향식 DP (memoization)
    - iterative 방식 : 상향식 DP (default DP)
    - 반복 구조가 memoizaiont 보다 성능 면에선 효율적
        - 재귀적 구조는 시스템 호출 스택을 사용하는 오버헤드 발생
    
    ※ A형 이상의 윗 단계를 해결하기 위한 방법
    

### DFS (depth-first search)

- 비선형적구조인 그래프 구조의 모든 자료 탐색
- 두 가지 방법
    - 깊이 우선 탐색 (Depth First Search, DFS)
    - 너비 우선 탐색 (Breadth First Search, BFS)
- DFS
    - 시작 점에서 한 방향으로 갈 수 있는 경로가 있는 곳까지 깊이 탐색
    
    ⇒ 더 이상 갈 곳이 없으면 만났던 갈림길로 돌아옴
    
    ⇒ 다른 방향으로 갈 수 있는 곳까지 깊이 탐색
    
    - 정점으로 돌아가서 다시 깊이우선 탐색을 반복해야 하므로
        
        **→ 후입선출 구조의 스택** 사용
        
- 탐색하는 방법
    1. 시작 정점 v를 결정하여 방문
    2. 정점 v에 인접한 정점 중
        1. 방문하지 않은 정점 w가 이으면, 정점 v를 스택에 push하고 정점 w 방문
        그리고 w를 v로 하여 다시 2)를 반복
        2. 방문하지 않은 정점이 없으면, 탐색 방향을 바꾸기 위해 스택 pop
        가장 마지막 방문 정점을 v로 하여 다시 2)를 반복
    3. 스택의 top이 -1이 될 때 까지 2) 반복
- pseudo code
    
    visited[], stack[] 초기화
    
    DFS(v)
    
    시작점 v 방문
    
    visted[v]에 방문 표시
    
    while 정점 점검
    
    if (v의 인접 정점 중 방문 안 한 정점 w가 있으면)
    
    v 푸시
    
    w 방문 표시
    
    else
    
    if (스택이 비어있지 않으면 = 방문 안한 곳이 없으면) 
    
    v 팝
    
    else (→ 전체 탐색 완료)
    
    break
    
    end DFS()
    
    - 저장 방식
        - 인접행렬
            
            → 행렬 안에 인접해 있는 좌표에 1 표기
            
        - adj-list  : 0~ n번 행 까지 생성 [[#0번행], [#1번행], [#3번행], … , [n번행]]
            
            → i 행에 i 번 정점에 인접한 정점 번호를 저장
