### 계산기1

- 문자열로 된 계산식이 주어질 때, 스택을 이용하여 이 계산식의 값을 계산할 수 있다.
- 문자열 수식 계산의 일반적인 방법
    1. *중위 표기법 → *후위 표기법 변경
        
        *중위 표기법 = A+B
        
        *후위 표기법 = AB+
        
    2. 후위 표기법 스택을 이용해 계산
- 코드로 구현하기
    
    step1. 중위 표기법에서 후위 표기법으로 변환 알고리즘
    
    1) 입력 받은 중위 표기식에서 토큰을 읽는다.
    
    2) 토큰이 피연산자이면 토큰을 출력한다.
    
    3) 토큰이 연산자(괄호포함)일 때, 이 토큰이 스택의 top에 저장되어 있는  연산자보다 우선순위가 높으면 스택에 push하고, 그렇지 않다면 스택 top의 연산자의 우선순위가 토큰의 우선순위보다 작을 때까지 스택에서 pop 한 후 토큰의 연산자를 push. top에 연산자 없으면 push
    
    - 연산 규칙
        - 연산자
            - 토큰의 icp를 스택의 탑에 있는 항목의  isp와 비교하여 우선순위가 높으면 push
                
                ※ 비어있으면 항상 push
                
            - 해당 토큰보다 낮으면 더 낮은 연산자가 나올 때까지 pop
                - 낮은 연사자 만나면 push
            - 닫는 괄호를 만나면, [괄호는 결국 버려짐]
                - 닫는 괄호를 버리고
                - 여는 괄호를 만날 때까지 pop (여는 괄호는 버리기)
            
            | 연산자 | icp(토큰상태) | isp(스택상태) |
            | --- | --- | --- |
            | ) | - | - |
            | * / | 2 | 2 |
            | + - | 1 | 1 |
            | ( | 3 | 0 |
        - 피연산자
            - 피연산자면 항상 출력
    
    ### 계산기2
    
    - 후위 표기법의 수식을 스택을 이용해 계산
        - 피연산자를 만나면
            - 피연산자를 만나면 스택에 push
        - 연산자를 만나면
            - 스택에서 피연산자를 두 번 pop하여 꺼내기
            - 피연산자 두개와 연산자를 계선하여 스택에 push
                
                ※ 먼저 나온 애가 피연산자의 오른쪽에 위치
                
        - 수식에서 더 이상 토큰이 없으면, 스택에서 최종 결과값 pop()
    
    ### 백트래킹 (Backtracking)
    
    - 해를 찾는 도중에 ‘막히면’ (즉, 해가 아니면) 되돌아가서 다시 해를 찾아 가는 기법
        
        ※ DFS와 굉장히 유사한 형태
        
    - 최적화 문제와 결정 문제를 해결할 수 있다.
        - 결정 문제 : 문제의 조건을 만족하는 해가 존재하는지의 여부를 ‘yes’ 또는 ‘no’로 답하는 문제
            - 미로 찾기 : 출구에 도착하는가? ⇒ 출구의 경로 수는? 출구까지 최소 거리는?
            - n-Queen 문제
            - Map coloring
            - 부분 집합의 합(Subset Sum) 문제
    - 백트래킹 vs DFS
        - 백트래킹은 노드에서 출발하는 경로가 해결책으로 이어지지 않을 것 같으면 경로를 따라가지 않는다 (prunning : 가지치기)
            - 가지치기를 잘하면 꽤 효율적이고 쓸만하다.
        - 불필요한 경로를 조기 차단
            - 예측, 후보군 추리기 등..
        - N!의 가지 경우의 수가 있으면 깊이우선탐색 불가능
        - 가지치기가 불가능하다면 백트래팅고 결국 최악의 경우에 지수함수 시간을 요함
    - 기법
        - 노드의 유망성 점검 → 유망하지 않으면 → 부모로 되돌아간 후 다시 자식으로 이동
    - 알고리즘 절차
        1. 상태 공간 트리의 깊이 우선 검색 실시
        2. 각 노드가 유망한지 점검
        3. 만일 그 노드가 유망하지 않으면, 그 노드의 부모 노드로 돌아가서 검색 진행
    
    e.g. 미로찾기
    
    - 스택
        - 갈 수 있는 곳이 있으면 현재 위치 push하고 갈 수 있는 곳으로 이동
        - 갈 수 있는 곳이 없으면 pop으로 돌아가기
            - 갈 수 있는 곳과 갈 수 없는 곳을 구분해 나가는 작업 필요
        
        ※ 각  칸을 다니면서, 갈 수 있는 유망한 곳을 스택에 쌓아 두고 → 갈 수 있는 곳이 없을 대 유망한 곳으로 바로 갈 수 있다.
