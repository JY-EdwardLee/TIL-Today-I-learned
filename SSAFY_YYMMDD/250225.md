### 웹 구조화

- HTML (HyperText Markup Language)
: 웹 페이지의 의미와 **구조**를 정의하는 언어
    
    ※ Hypertext : 웹 페이지를 다른 페이지로 연결하는 링크, 참조를 통해 사용자가 한 문서에서 다른 문서로 즉시 접근할 수 있는 텍스트 (비선형성, 상호연결성, 사용자 주도적 탐색)
    
    ※ Markup Language : 태그 등을 이용하여 문서나 데이터의 구조를 명시하는 언어
    
- HTML 구조
    - 가장 기본적이 뼈대 구조
        - <!DOCTYPE html>
            - 해당 문서가 html 문서라는 뜻
        - <html></html>
            - 전체 페이지의 콘텐츠를 포함
            - <head></head>
                - 사용자에게 보이지 않음(엄밀히 따지면 페이지 바깥에 있는 영역)
                - 컴퓨터가 식별하는 메타데이터 작성
                - <title> 페이지명 (탭에서 확인 가능)
            - <body></body>
                - HTML 문서의 내용을 나타내는 영역
        - <title></title>
            - 브라우저 탭 및 즐겨찾기 시 표시되는 제목으로 사용
- HTML Element(요소)
    - 하나의 요소는 **여는 태그**와 **닫는 태그**(앞에 /표기), 그리고 **내용**으로 구성됨
- HTML Attributes(속성)
    - 사용자가 원하는 기준에 맞도록 요소를 설정하거나 다양한 방식으로 요소의 동작을 조절하기 위한 값
    - 목적
        - 나타내고 싶지 않지만 추가적인 기능, 내용을 담고 싶을 때 사용
        - CSS에서 스타일 적용을 위해 해당 요소를선택하기 위한 값으로 활용됨
    - 작성 규칙
        1. 요소 이름과 속성 사이에 공백 <p:✅class = “>
        2. 하나 이상의 속성이 있으면 속성 사이에 공백 <p:class = “”✅href= “”>
        3. 속성 값은 열고 닫는 따옴표로 표기
- HTML 작업 기초
    - ! → 자동 완성
    - heading & paragraph
        - <h1> 속성 : **문서의 최상위 제목** 이라는 의미
            - h1 ~ h6,  p
    - list
        - ol, ul, li
    - Emphasis & importance
        - em, strong
    

### 웹 스타일링

- **CSS (Cascading Style Sheet)**
웹 페이지의 **디자인**과 **레이아웃**(배치)을 구성하는 언어
- CSS 구문
    
    ```css
    h1(선택자) {
    color(속성) : red(값); #선언/Declaration
    }
    ```
    
    - 선언의 끝에는 항상 ;(세미콜론)을 작성
- **스타일링**
    1. 인라인(inline) 스타일
        
        : HTML 요소 안에 style 속성 값으로 작성
        
    2. 내부(internal) 스타일 시트
        
        : head 태그 안에 style 태그에 작성
        
    3. 외부(external) 스타일 시트
        
        : 별도 CSS 파일 생성 후 HTML link 태그를 사용해 불러오기

### CSS Box Model

- **CSS Box Model**
    
    : 웹 페이지의 모든 HTML 요소를 감싸는 사각형 상자 모델
    
    e.g. 원은 네모 박스를 깎은 것..
    
- **박스 타입 (outer display type)**
    1. Block box
        - 아래로 쌓이는 타입
    2. Inline box
        - 오른쪽으로 사이는 타입
        
        ⇒ 박스 타입에 따라 페이지에서의 배치 흐름 및 다른 박스와 관련하여 박스가 동작하는 방식이 달라짐
        
- **박스 표기 타입**
    1. Outer display type
        - 박스가 문서 흐름에서 어떻게 동작할 지를 결정
        
        → block
        
        - **항상 새로운 행으로 나뉨**
        - width와 height 속성 사용
        - padding, margin, border로 다른 상자 밀어내기
        - width 속성을 지정하지 않으면 박스는 inline 방향으로 사용 가능한 공간을 모두 차지함
            - 상위 컨테이너 너비 100%로 채우는 것
        - 대표적인 block 타입 태그 : h1~6,  p, div
        
        → inline
        
        - 새로운 행으로 안넘어감
        - width와 height  속성 사용 가능
    2. Inner display type (Flexbox)
        - 박스 내부의 요소들이 어떻게 배치될지를 결정
        - 속성
            - flex
        
        ※ 추후 CSS layout - flexbox에서 진행 예
        
- CSS Box Model
    - 웹 페이지의 모든 HTML 요소를 감싸는 사각형 상자 모델
- 박스의 4가지 구성 요소
    - content box
        - 실제 콘텐츠가 표시되는 영역 크기
        - **width 및 height 속성**을 사용하여 크기 조정
    - padding box
        - 콘텐츠 주위에 공백
        - padding 관련 속성 (top, bottom, left, right)
    - border box
        - 콘텐츠와 패딩을 래핑
        - border관련 속성 (top, bottom, left, right)
    - margin box
        - 콘텐츠, 패딩 및 테두리를 래핑
        - 박스와 다른 요소 사이의 공백
        - margin 관련 속성 (top, bottom, left, right)
    
    ※ shorthand(width - style - color)가 있어서 기본적인 형식을 한번에 작성 가능하다
    
    ㄴ margin과 padding 4방향 속성을 한번에 지정할 수 있다 .
    
    ㄴ 1개 - 공통, 2개 상하/ 좌우, 3개 상/좌우/하, 4개 상우하좌
    
- The standard CSS box model
    - 표준 상자 모델에서 width와 height 속성 값을 설정하면, 이 값은 content box의 크기를 조정하게 됨
    - 실제 박스는 **보더, 패딩 값을 모두 더한 값**임
    
    ⇒ CSS는 border box가 아닌 content box의 크기를 width로 맞춤
    
    - box-sizing을 전역 설정할 수 있음
- 기타 display 속성
    1. inline-block
        - lnline과 block 요소의 중간 지점 제공 하는 displary 값
            
            (양 쪽의 적절한 장점을 가져옴)
            
        - width, height 속성 사용 가능 (block의 특징)
        - padding, margin 및 border로 인해 다른 요소가 상자에서 밀려남 (blcok의 특징)
        - 새로운 행으로 넘어가지 않음 (인라인 특징)
        
        ⇒ 요소가 줄 바꿈이 되지는 않으면서 너비와 높이를 적용하고 싶은 경우 사용
        
    2. none
        - 요소를 화면에 표시하지 않고, 사라지게 함 (공간조차 부여되지 않음)
            - 코드에서는 확인 가능

### CSS Layout

- 각 요소의 **위치**와 **크기를 조정**하여 웹 페이지의 디자인을 결정하는 것
    
    ⇒ DIsplay, Position, Flexbox 등
    
- **CSS Position**
    - 요소를 Normal Flow에서 **제거**하여 다른 위치로 배치하는 것
        
        ⇒ 다른 요소 위에 올리기, 화면의 특정 위치에 고정시키기 등
        
    - Position의 이동 방향 5가지
        - top, left, right, bottom (기본 4방향 trbl)
            
            +) Z Axis (화면이 겹치는 방햐)
            
    - Position 유형
        1. static (기본)
            - Normal Flow에 따라 배치
            - trbl 적용 안됨
            - 기본 값
        2. relative (상대)
            - 자신의 원래 위치(static)을 기준으로 이동
            - trbl로 이동
            - 다른 요소의 레이아웃에 영향을 주지 않음 (요소가 차지하는 공간은 static일 때와 같음)
        3. absolute (절대) - 본인의 static 영역을 버림 (비워짐)
            - 요소를 Normal Flow에서 제거
            - 가장 가까운 relative 부모 요소를 기준으로 이동
                - 만족하는 부모 요소가 없다면 body 태그를 기준으로
            - trbl로 위치 조정
            - 문서에서 요소가 차지하는 공간이 없어짐
        4. fixed (고정)
            - 요소를 Normal Flow에서 제거
            - 현재 화면영역(viewport)을 기준으로 이동
            - 스크롤해도 항상 같은 위치에 유지됨
            - trbl로 위치 조정
            - 문서에서 요소가차지하는 공간 없어짐
        5. sticky (스티키)
            - relative와 fixed의 특성을 결합한 속성
            - 스크롤 위치가 임계점에 도달하기 전에는 relative
            - 특정 임계점에 도달하면 fixed처럼 동작하여 화면에 고정됨
            - 만약 다음 sticky 요소가 나오면 다음 sticky 요소가 이전 sticky 요소의 자리로 대체 됨

### z-index

- 요소의 쌓임 순서
- 정수 값을 사용해 Z축 순서를 지정
- 값이 클수록 요소가 위에 쌓이게 됨
- static이 아닌 요소에만 적용됨
- 특징
    - 기본값은 auto
    - 부모 요소의 z-index 값에 영향을 받음
    - 같은 부모 내에서만 z-index 값을 비교
    - 부모의 z-index가 낮으면 자식의 z-index가 아무리 높아도 부모보다 위로 올라갈 수 없음
    - z-index 값이 같으면 HTML 문서 순서대로 쌓임

### CSS Flexbox

- 요소를 행과 열 형태로 배치하는 1차원 레이아웃 방식
    
    ⇒ 공간 배열 & 정렬
    

※ Inner display type

- Inner display type
    - 박스 내부의 요소들이 어떻게 배치될 지를 결정
    - 속성:flex
- flexbox 구성 요소
    - main axis : main start ↔ main end
        - start → end 방향으로 배치 (기본 값)
    - cross axis : cross start ↕️ cross end
        - start → end 방향으로 배치 (기본 값)
- Flex Container
    - display : flex 혹은 display : inlline-flex가 설정된 부모요소
    - 1차 자식 요소들이 Flex item이 됨

## Flexbox 속성 목록

- Flex Container 관련 속성
    - display, flex direction, flex-wrap, justify-content, align-items, align-content
- Flex item 관련 속성
    - 
1. Flex Container 지정
    - flex item은 기본적으로 행으로 나열
    - flex item은 주 축의 시작 선에서 시작
    - flex item은 교차 축의 크기를 채우기 위해 늘어남
2. flex-direction
    - flex item이 나열되는 방향을 지정
    - column으로 지정할 경우 주축이 변경됨
    - -reverse로 지정하면 start와 end 위치 바뀜
3. flex-wrap
    - 한 행에 flex item 들어가지 않을 경우 다른 행에 배치할지 여부 결정
4. justify-content
    - 주 축을 따라 flex tiem과 주위 공간을 분배
5. align-content ( 여러 줄 정렬 vs 한 줄 정렬)
    - 교차 축을 따라 flex item과 주위 공간을 분배
        - flex-wrap이 wrap또는 wrap-reverse로 설정된 여러 행에만 적용됨
        - 한 줄 짜리 행에는 효과 없음 (flex-wrap이 nowrap으로 설정된 경우)
6. align-items
    - 교차 축을 따라 flex item 행을 정렬
7. align-self
    - 교차 축을 따라 개별 flex item을 정렬
8. flex-grow (↔ flex shrink)
    - 남는 행 여백을 비율에 따라 각 flex item에 분배
        - 아이템이 컨테이너 내에서 확장하는 비율을 지정
9. flex-basis
    1. flex item의 초기 크기 값을 지정
    2. flex-basis와 width 값을 동시 적용한 경우 flex-basis가 우
- 목적에 따른 속성 분류
    1. 배치
        
        : flex-direction, flex-wrap
        
    2. 공간 분배
        
        : justify-content, align-content
        
    3. 정렬
        
        : align-items, align-self
        
- 반응형 레이아웃
    - 다양한 디바이스와 화면 크기에 자동으로 적응하여 콘텐츠를 최적으로 표시하는 웹 레이아웃 방식
