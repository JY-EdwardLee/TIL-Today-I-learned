# Auth

### Cookie & Session

- HTTP
    - HTML 문서와 같은 리소스들을 가져올 수 있도록 해주는 규약 웹(WWW0에서 이루어지는 모든 데이터 교환의 기초
    - 특
        - 비 연결 지향 : 서버는 요청에 대한 응답을 보낸 후 연결을 끊음
        - 무상태 : 연결을 끊는 순간 클라이언트와 서버 간의 통신이 끝나며 상태 정보가 유지되지 않음 (e.g. 로그인 상태가 유지되지 않음..)
- 쿠키
    - 서버가 사용자의 웹 브라우저에 전송하는 작은 데이터 조각
        
        ⇒ 서버가 제공하여 클라이언트 측에서 저장되는 작은 데이터 파일
        
        ⇒ 사용자 인증, 추적, 상태 유지 등에 사용되는 데이터 저장 방식아이콘 추가
        
    - HTTP는 비연결 지향이기 때문에, 쿠키를 이용해서 상태를 유지
        1. set cookie : 쿠키에 상태 정보를 담아서 클라이언트에게 쿠키를 저장하도록 전달
        2. 쿠키 데이터를 통해 상태 확인
        3. 매 요청마다 쿠키를 전달해서 상태 유지
    - 저장 방식
        - key-value 형식으로 저장 (이름, 값 외에도 만료 시간 등 추가 속성 포함)
    - 전송 과정
        - Set-Cookie 필드를 통해 클라이언트에게 쿠키 전송
        - 브라우저는 받은 쿠키를 저장해 두었다가, 동일한 서버에 재요청 시 HTTP 요청 Header의 Cookie 필드에 저장된 쿠키를 함께 전송
    - 주요 용도
        - 두 요청이 동일한 브라우저에서 들어왔는지 아닌지 판단
            - 로그인 상태 유지
        - HTTP 프로토콜의 상태 정보 기억
        
        ⇒ 서버에게 로그인된 사용자라는 인증 정보가 담긴 쿠키를 매 요청마다 계속 보내는 것
        
    - why 쿠키?
        - 세션 관리 (e.g. 로그인, 장바구니 등..)
        - 개인화
        - 트래킹
- 세션
    - **서버 측에서 생성**되어 클라이언트와 서버 간의 **상태를 유지**
    - 상태 정보를 저장하는 데이터 저장 방식
        
        ⇒ 쿠키에 세션 데이터를 저장하여 매 요청시마다 세션 데이터를 함께 보
        
    - 작동 원리
        - 로그인 인증 성공 시 session 데이터(A라는 사용자의 인증 정보) 생성, 저장
        - session 데이터의 session id(키) 발급
        - sesson id 클라이언트에게 응답(전달)
        - 클라이언트는 session id를 쿠키에 저장
        - 동일한 서버에 접속 요청과 함께 session id가 저장된 쿠키를 서버에 전달
        - 서버는 session id를 확인해 로그인 상태 확인

### 비밀번호 변경

- 인증된 사용자의 Session 데이터를 Update 하는 과정
- PasswordChangeForm()
    - 비밀번호 변경 시 사용자 입력 데이터를 받는 built-in **Form**
    - 암호화 과정이 있어서 바로 DB에 들어가지 않음
- 비밀번호가 변경되면
    - 기존 세션과 회원 인증 정보가 일치하지 않게 됨 → 로그인 상태 유지 불가능
    - 위를 방지하는 함수
        - update_session_auth_hash(request, user)
            - 암호가 변경되면 새로운 password의 session data로 기존 session을 자동으로 갱

```python
def change_password(request, user_pk):
    if request.method == 'POST':
        form = PasswordChangeForm(request.user, request.POST)
        if form.is_valid():
            user = form.save() # 변경된 user 데이터 변수로 저장
            update_session_auth_hash(request, user) # 세션 갱신 함수
            return redirect('articles:read')
    else:
        form = PasswordChangeForm(user=request.user)
    context = {
        'form': form
    }
    return render(request, 'accounts/change_password.html', context)
```
