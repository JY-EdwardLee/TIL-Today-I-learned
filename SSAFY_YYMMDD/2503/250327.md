# ORM

### ORM (Object-Relational-Mapping)

- 객체 지향 프로그래밍 언어를 사용하여 호환되지 않는 유형의 시스템 간에 데이터를 변환하는 기술

### QuerySet API

- ORM에서 데이터를 검색, 필터링 정렬 및 그룹화 하는 데 사용하는 도구
    
    ⇒ API를 사용하여 SQL이 아닌 Python 코드로 데이터를 처리
    
    - 역할 : python의 모델 클래스와 인스턴스를 활용해 DB에 데이터를 저장, 조회, 수정, 삭제하는 것
- QuerySet API를 쏘면 QuerySet or Instance를 보내준다.
- QuerySet API 구문 (이 자체로 **메서드**다)
    - Model_class.Manager.Querset_API(메서드)
        
        e.g. Article.objects.all()
        

- Query
    - 데이터베이스에 특정한 데이터를 보여 달라는 요청
    - 파이썬 작성 코드 → ORM → SQL로 변환 → 데이터베이스 → 응답 데이터 → ORM → QuerySet → 확인
- QuerySet
    - 데이터베이스에서 전달 받은 객체 목록(데이터 모음)
        - 순회 가능한 데이터, 1개 이상의 데이터 불러올 수 있음
    
    ※ **단, 단일 객체 반환 시 모델(class)의 인스턴스로 반환 됨**
    

- CRUD
    - 소프트웨어가 가지는 기본적인 데이터 처리 가능
        - Create(저장), Read(조회), Update(갱신), Delete(삭제)
    - CRUD 도와주는 외부 라이브러리
        - pip install ipython django-extensions (끝나고 freeze  reuirements 해주기)

- Django shell
    - Django 환경 안에서 실행되는 python shell
    (입력하는 QuerySet API 구문이 Django 프로젝트에 영향을 미침)
    - 그냥 shell vs plus_shell(django-extensions 지원)
        - plus shell은 미리 장고 및 환경에서 필요한 사항들을 import 해줌
1. Create
- 데이터 객체 만들기 C(reate)는 3가지 방법이 있음
    
    방법 1) 
    
    1. 변수에 class 선언 해주기
    2. 인스턴스 변수에 값 작성하기
    3. 저장하기 (변수.save())
    
    방법 2)
    
    1. 변수에 class 선언하면서 필드값 입력해주기
    2. 저장하기 (변수.save())
    
    방법 3)
    
    1. 생성 메서드 사용하기 (Artice.objects.create(필드값)
        
        ※ 세이브까지 한번에 진행됨
        
1. Read
- 대표적인 조회 메서드 all, filter, get
    - Return new  QuerySets(여러 객체) ⇒ [], return이 있으므로 변수에 담을 수 있음
        - all
            - 전체 데이터 조회
            
            e.g. Article.objects.all()
            
        - filter
            - **주어진 매개변수(조건)**와 일치하는 객체를 포함하는 QuerySet 반환
            - 항상 querysets 형식으로 반환
            
            e.g. Article.objects.filter(title=’second’)
            
    - Do not return QuerySets(단일 객체) ⇒ 리스트 형식 아님
        - get (PK 조회용)
            - 주어진 매개변수와 일치하는 객체를 반환
            - 단일 변수가 아니면 (0개 또는 2개 이상) 에러 발생
            
            ⇒ 메소드의 특징으로 인해, **pk와 같이 고유성을 보장하는 조회**에서만 사용해야
            

1. Update
    - 조회 → 수정 → 저장
    - .save()
        - 인스턴스 변수를 변경 후 save 메서드 호출
        1. 인스턴스 조회 (read가 우선 되어야 함)
        2. 인스턴스 변수 변경
        3. 저장
2. Delete
    - 조회 → 삭제
    - delete 메서드 호출

### ORM with view

- view 함수에서 ORM 하기 (QuerySet API)
    - shell에서 썼던 함수는 모두 view에서도 쓸 수 있다.
    - 이를 기반으로 CRUD를 하는 함수를 view에 작성해보자

### Field lookups

- 단순 조회 → 세부 조회 (e.g. OO으로 시작하는, 포함하는, 끝나는)
    - __(던더스코어, 더블 언더스코어) 뒤에 명령 작성
