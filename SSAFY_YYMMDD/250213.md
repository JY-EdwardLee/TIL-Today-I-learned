# stack 1
### 스택

- 특성
    
    : 마지막에 삽입한 자료를 가장 먼저 꺼낸다.
    
    - **후입선출(LIFO,Last-In-First_Out)** 이라고 부른다.
- 연산
    - 삽입 : 저장소에 자료를 저장한다. 보통 **push**라고 부른다.
    - 삭제 : 저장소에서 자료를 꺼낸다. 꺼낸 자료는 삽입한 자료의 역순으로 꺼낸다. 보통 **pop**이라고 부른다.
    - 스택이 공백인지 아닌지를 확인하는 연산. **isEmpty**
    - 스택의 top에 있는 item(원소)을 반환하는 연산. **peek**
- 고려 사항
    - 최초에 고정해 놓은 크기로 하기 때문에 크기를 변경하기 어렵다는 단점이 이다.
    - 이를 위해 저장소를 동적으로 할당하여 스택을 구현하는 방법이 있다.
        
        ⇒ **동적 연결리스트**를 이용하여 구현하는 방법. 구현이 복잡하지만 메모리 효율이 좋음

- 스택의 구현
    
    ```python
    def push(item, size):
    	global top
    	top += 1
    	if top == size:
    		print(’overflow!’)
    	else:
    		stack[top] = item
    
    # 준비작업
    size = 10
    stack = [0]*size
    top = -1
    
    push(10, size)
    top += 1 # push(20)         
    stack[top] = 20 #
    ```
    
- 스택의 pop 알고리즘
    - pop 메소드를 통해 리스트의 마지막 데이터를 pop
        
        ```python
        def pop():
        	if len(s) == 0:
        		# underflow
        		return
        	else:
        		return s.pop() # 괄호 안 비워두기
        ```
        
- 스택의 pop 알고리즘
    
    ```python
    def pop():
    	global top
    	if top == -1:
    		print('underflow')
    		return 0
    	else:
    		top -= 1 # top은 -1이 되지만 메모리 상 top의 위치는 살아 있다.
    		return stack[top+1]
    print(pop())
    
    if top > -1: #pop()
    	top -= 1
    	print(stack[top+1])
    ```
    

### 스택의 응용 1 : 괄호검사

- 괄호의 종류 : [], {}, ()
- 조건
    1. 왼쪽과 오른쪽 괄호의 개수 같아야함
    2. 같은 괄호일 시 왼쪽 괄호는 오른쪽 괄호보다 먼저 나와야 함
    3. 괄호 사이에는 포함 관계만 존재
- 스택을 이용한 괄호 검사
    - 여는 괄호 등장 시 → push
    - 닫는 괄호 등장 시 → pop
    
    했는데 괄호가 스택에 남아 있으면 **error**
    
    닫는게 나와서 pop을 했는데 스택이 비어있으면 **error**

### 재귀호출

- 필요한 함수가 자신과 같은 경우 자신을 다시 호출하는 구조
- 상황에 따라 재귀호출 방식을 사용하여 함수를 만들면 프로그램의 크기를 줄이고 간단하게 작성

e.g. factorial

- n에 대한 facorial : 1부터 n까지의 모든 자연수를 곱하여 구하는 연산
    
    n! = n x (n-1)!
    
    (n-1)! = (n-1) x (n-2)!
    
    (n-2)! = (n-2)x (n-3)!
    

e.g. 피보나치

```python
def fibo(n):
	if n < 2:
		return n
	else:
		return fino(n-1) + fibo(n-2)
```
