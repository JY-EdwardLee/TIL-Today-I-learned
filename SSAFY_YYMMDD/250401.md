# Static files

### Static files (정적파일)

- 서버 측에서 변경되지 않고 고정적으로 제공되는 파일
    
    (이미지, JS, CSS 파일 등)
    
- 웹 서버와 정적 파일
    - 웹서버의 기본동작은 **특정 위치(URL)에 있는 자원**을 요청(HTTP reqeust) 받아서 응답(HTTP response)을 처리하고 제공하는 것
    - 자원에 접근 가능한 주소가 있다.
    
    ⇒ 정적 파일을 제공하기 위한 **경로(URL)**가 있어야 한다.
    

- **Static files 기본 경로**
    
    ※ app폴더/static/ (위치를 다른 곳에 두면 동작하지 않음)
    
- 기본 경로 static file 제공하기
    1. articles/static/srticles/ 경로에 이미지 파일 배치
    2. (DTL) stactic tag를 사용해야함
        - load tag를 사용해 import 후 사용 가능
            
            {% load static %}
            
        - src에 static 태그 “경로”(약속된 경로 생략) 작성
    3. static_url로 확인 가능
- STATIC_URL
    - 기본 경로 및 추가 경로에 위치한 정적 파일을 참조하기 위한 URL
        
        ⇒ 실제 파일이나 디렉토리 경로가 아니며, URL로만 존재
        
        ※ settings의 STATUL_URL에 적용된 경로값에 따라 생성됨
        
        URL + STATIC_URL + 정적파일 경로
        
        (= http://127.0.0.1:8000/static/articles/sample-1.png)
        

- **Static files 추가 경로**
    - STATICFILES_DIRS에 문자열 값으로 추가 경로 설정
    - 추가 경로도 항상 폴더 안에 있어야
    1. settings.py
    2.  STATICFILES_DIRS 배열 생성
    3. BASE_DIR/ ‘경로(폴더명)’ 작성

### Media files

- 사용자가 웹에서 업로드하는 정적 파일 (user-uploaded)

- 이미지 업로드
    - ImageField()
        - 이미지 업로드에 사용하지 모델 필드
            
            ※ 이미지 객체가 직접 DB에 저장되는 것이 아닌 ‘**이미지 파일의 경로’** 문자열이 저장됨
            
- 미디어 파일 제공 준비사항
    1. MEDIA_ROOT, MEDIA_URL 설정
    2. ROOT와 URL에 대한 URL 지정

1. MEDIA_ROOT : 미디어 파일들이 위치하는 디렉토릐 절대 경
2. MEDIA_URL : MEDIA_ROOT에서 제공되는 미디어 파일에 대한 주소를 생성 STATIC_URL과 동일한 역할)
3. project의 url 지정
    - django 설명서 참조

- **이미지 업로드하기**
    - models 파일 내 db 정보 수정
        - models.ImageField로 만들어진 속성 image 추가
            
            ※ pillow 라이브러리 필수 설치, blank=True
            
        - 마이그레이션
    - html > form 요소의 enctype 속성 추가
        - enctype = “multipart/form-data”
    - view >  생성 함수
        - ModelForm의 2번째 위치 인자로 request.FILES 추

- **업로드 이미지 제공하기**
    1. ‘url’ 속성을 통해 업로드 파일의 경로값을 얻을 수 있음
    2. article.image.url : 업로드 파일의 경로
    3. article.image : 업로드 파일의 파일 이름

- **업로드 이미지 수정하기/삭제하기**
    - 수정하기
        1. 수정html > form 요소 > enctype 속성 추가
        2. update view 함수 > 에 업로드 파일에 대한 추가 코드 request.FILES 작성
    - 삭제하기
        - 다양한 라이브러리를 통해 media 경로에 쌓인 이미지를 지울 수 있다.
