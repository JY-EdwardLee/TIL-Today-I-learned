# TREE

### 트리

- 비선형 구조 (원소들 간에 1:n 관계를 가지는 자료구조)
- 원소들 간에 계층관계를 가지는 계층형 자료구조
- 상위 원소에서 하위 원소로 내려가면서 확장되는 트리(나무)모양의 구조
- **정의 :** 한 개 이상의 노드로 이루어진 유한 집합
    - **최상위 노드**를 정해야함 ⇒ 루트(root) = 최상위 노드
    - 나머지 노드들은 n개의 분리 집합으로 분리 가능 ⇒ 서브 트리
    - T1 ~ TN(서브트리) 는 하나의 트리(재귀)가 됨
        - 가장 끝에 있는 노드 = leaf(잎) 노드
    - 간선 : 노들르 연결하는 선, 부모 노드와 자식 노드를 연결
        - 부모 노드, 자식 노드 = 상위 노드, 하위 노드
        - 형제 노드 : 같은 부모 노드의 자식 노드
        - 조상 노드 : 간선을 따라 루트 노까지 이르는 경로에 있는 모든 노드들
        - 자손 노드 : 서브 트리에 있는 하위 레벨의 노드
    - 차수
        - 노드의 차수 : 노드에 연결된 자식 노드의 수
        - 트리의 차수 : 트리에 있는 노드의 차수중에서 가장 큰 값
        - 리 노드 : 차수가 0인 노드
    - 높이
        - 노드의 높이 : 루트에서 노드에 이르는 간선의 수
        - 트리의 높이 : 트리에 있는 노드의 높이 중에서 가장 큰 값

## 이진 트리

- 모든 노드들이 2개의 서브트리를 갖는 특별한 형태의 트리
- 각 노드가 자식 노드를 최대 2개 까지만 가질 수 있는 트리
    - 0, 1, 2개
- 특성
    - 레벨 i에서의 노드의 최대 개수는 2^i개
    - 높이 h(0부터)인 이진 트리의 노드 개수는 (h+1) ≤ 노드 개수 ≤ 2^(h+1) - 1
- 종류
    - 포화 이진 트리(Full Binary Tree)
        - 모든 레벨에 노드가 포화상태로 차 있는 이진 트리
        - 노드의 개수 : 2^(h+1) - 1
        - 루트를 1번으로 하여 정해진 위치에 대한 노드 번호를 가짐
    - 완전 이진 트리 (Complete Binary Tree)
        - 높이가 h이고 노드 수가 n개일 때, 포화 이진 트리의 노드 번호 1번부터 n번까지 빈 자리가 없는 이진 트리
    - 편향 이진 트리 (skewed)
        - 높이 h에 대한 최소 개수로 이루어진 이진트리
- 순회 : 트리의 노드들을 체계적으로 방문하는 것
    - 선후 관계가 없는 트리는 순회를 위한 특별한 방법이 필요하다.
    - 3가지 방법
        - 전위순회 VLR
            - 부모 → 자식좌 → 자식우
        - 중위순회 LVR
            - 자식좌 → 부모 → 자식우
        - 후위순회 LRV
            - 자식좌 → 자식우 → 부모
- 전위 순회
    - 수행 방법
        1. 현재 노드 n을 방문처리
        2. 현재 노드 n의 왼쪽 서브트리 이동
        3. 현재 노드 n의 오른쪽 서브트리로 이동
    
    ```markup
    (pseudo)
    def preorder_traberse(T):
    	if T:
    		visit(T)
    		preorder_traverse(T.left)
    		preorder_traverse(T.right)
    ```
    
- 중위 순회
    - 수행 방법
        1. 현재 노드 n의 룅ㄴ족 서브트리 이동
        2. 현재 노드 n을 방문하여 처리
        3. 현재 노드 n의 오른쪽 서브트리 이동
    
    ```markup
    (pseudo)
    def preorder_traberse(T):
    	if T:
    	  preorder_traverse(T.left)
    		visit(T)
    		preorder_traverse(T.right)
    ```
    
- 후위 순회 (특 : 루트가 가장 마지막에 처리)
    - 수행 방법
        1. 현재 노드 n의 왼쪽 서브트리로 이동
        2. 현재 노드 n의 오른쪽 서브트리로 이동
        3. 현재 노드 n을 방문하여 처리
    
    ```markup
    (pseudo)
    def preorder_traberse(T):
    	if T:
    	  preorder_traverse(T.left)
    		preorder_traverse(T.right)
    		visit(T)
    ```
    

### 이진 트리의 표현

1. 포화/완전 이진 트리의 정점 번호를 따를 때
    - 배열을 이용한 이진 트리의 표현
        - 이진 트리에 각노드 번호를 부여
            - 루트 번호 1번
            - 레벨 n에 있는 노드에 대하여 왼쪽부터 오른쪽으로 2^n → 2^(n+1) - 1 까지
        - 포화, 완전 이진트리
    - 노드 번호의 성질
        - 노드 번호가 i인 노드의 부모 노드 번호 = i//2
        - 노드 번호가 i인 노드의 왼쪽 자식 노드번호 2*i
        - 노드 번호가 i인 노드의 오른쪽 자식 노드 번호 2*i + 1
        - 레벨 n의 노드 번호 시작 번호 2^n

    - 자식은 최대 2명이기에, 자식 array(1차원 배열)가 두개가 되줘야 함

2. 자식 번호를 인덱스로 부모 번호 저장
    - 부모는 하나이기에, 부모 array(1차원 배열) 하나면 됨
    
    for i : 1 → N
    
    read p, c
    
    par[c] = p
    
    - 루트 찾기, 조상 찾기 할 때 사용

- 배열을 이용한 이진트리의 단점
    - 메모리 공간 낭비
    - 노드 삭제시 배열 크기 변경 어려움
- **연결 리스트**
    - 하나의 배열에
        - 왼쪽 자식 노드 주소 | 데이터 | 오른쪽 자식 노드 주소
- **수식 트리**
    - 수식을 표현하는 이진 트리
        - 피연산자 = 리프노드
        - 연산자 = 루트 or 가지 노드
