# Bootstrap

### Bootstrap

- CSS 프론트엔드 프레임워크(Toolkit)
    
    ※ css 생산성을 높이기 위한 미리 만들어 놓은 디자인 요소들을 제공하여 웹 사이트를 빠르고 쉽게 개발할 수 있도록 함
    
- 부트스트랩 배경지식
    - <link> 태그, <script> 태그로 css, js 로드
    - CDN(Content Deliver Network) 을 통해서 파일 로드
    - min 형식으로 css를 압축해서 빠르게 로드하는 방식을 차용
    - 모든 스타일을 클래스로 지정해 두었다.
- 기본 사용법
    - {property}{sides}-{size} (스타일 표현방식)
    
    | Abbreviation | Meaning |
    | --- | --- |
    | m | margin |
    | p | padding |
    
    | Abbreviation | Meaning |
    | --- | --- |
    | t | top |
    | b | bottom |
    | s | left |
    | e | right |
    | y | top, bottom |
    | x | left, right |
    | (blank) | 4 sides |
    
    | Abbreviation | rem Value | px Value |
    | --- | --- | --- |
    | 0 | 0 rem | 0px |
    | 1 | 0.25 rem | 4px |
    | 2 | 0.5 rem | 8px |
    | 3 | 1 rem | 16px |
    | 4 | 1.5 rem | 24px |
    | 5 | 3 rem | 48px |
    | auto | auto | auto |

### Reset CSS

- 모든 HTML 요소 스타일을 일관된 기준으로 재설정하는 간결하고 압축된 규칙 세트
    
    ⇒ HTML Element, Table, List 등의 요소들에 일관되게 스타일을 적용 시키는 기본 단계
    
    ※ 모든 브라우저 기본 html에 맞게 임의로 태그 스타일이 들어가 있다. (User-agent stylesheets)
    
- 모두 똑같은 스타일 상태로 만들고 스타일 개발을 시작하기 위해
- Normalize CSS (가장 대표적인 Reset CSS 방법론 중 하나)
    - 부트스트랩 reset 방식
    - 웹 표준 기준으로 브라우저 중 하나가 불일치 한다면 차이가 있는 브라우저를 수정하는 방법
        - 경우에 따라 IE 또는 EDGE 브라우저는 표준에 따라 수정할 수 없는 경우도 있는데, 이 경우 IE 또는 EDGE의 스타일을 나머지 브라우저에 적용
        (가장 저수준에게 맞춰주기)

### Sementic Web

- **웹 데이터를** **의미론적으로 구조화**된 형태로 표현하는 방식
    
    ※요소가 시각적으로 어떻게 보여질까? ⇒ 요소가 가진 목적과 역할은 무엇일까?
    
- HTML 요소가 의미를 가진다는 것
    - 같은 폰트 크기를 가진 <p> 태그와 <h1> 태그
        
        → 아무거나 써도 괜찮나?
        
- HTML semantic Element
    - 기본적인 모양과 기능 이외에 의미를 가지는 HTML 요소
        
        ⇒ 검색엔진 및 개발자가 웹 페이지 콘텐츠를 이해하기 쉽도록
        
    - 대표적인 semantic element
        
        header, nav, main, article, section, aside, footer
        
        위 요소는 모두 div와 같은 역할을 한다. (기능은 완전히 같지만, 의미를 가지는 태그들)
        

## Semantic in CSS

- CSS 방법론
    - CSS를 효율적이고 유지 보수가 용이하게 작성하기 위한 일련의 가이드라인
- OOCSS (Object Oriented CSS)
    - 객체 지향적 접근법을 적용하여 CSS를 구성하는 방법론
    - 기본 원칙
        1. **구조**와 **스킨**을 분리 (부트스트랩 방식)
            - 모든 버튼의 **공통** 구조를 정의 + **각각**의 스킨(배경색과 폰트 색상)을 정의
            
            e.g. 버튼 정의 + 색상 정
            
        2. **컨테이너**와 **콘텐츠**를 분리
            - 객체에 직접 적용하는 대신 객체를 둘러싸는 컨테이너에 스타일을 적용
            - 스타일을 정의할 때 위치에 의존적인 스타일을 사용하지 않도록 함
            - 콘텐츠를 다른 컨테이너로 이동시키거나 재배치할 때 스타일이 깨지는 것을 방식

### 참고

- why Bootstrap?
    - 가장 많이 사용되는 CSS 프레임워크
    - 사전에 디자인된 다양한 컴포넌트 및 기능 (빠른 개발과 유지보수)
    - 손쉬운 반응형 웹 디자인 구현
    - 커스터마이징 용이
    - 크로스 브라우징 지원
        - 모든 주요 브라우저에서 작동하도록 설계되어 있음
- CDN 없이 사용하기
    - 직접 파일 다운로드 받아서 적용하기
        - bootstrap.css or bootstrap.min.css와 bootstrap.bundle.js 선택
- 의미론적 마크업이 필요한 이유
    - 검색엔진 최적화(SEO)
        - 검색 엔진이 해당 웹 사이트를 분석하기 쉽게 만들어 검색 순위에 영향을 줌
    - 웹 접근
- **rem vs em**
    - **rem(root em) 단위**
        - 루트 요소(16px)을 기준으로 하는 상대적인 단위
        - 일관성있게 하기 위하여
        - 대부분의 사이즈에 다 쓰게
    - **em**
        - 부모요소의 폰트 크기 기준을 따라서 변환
