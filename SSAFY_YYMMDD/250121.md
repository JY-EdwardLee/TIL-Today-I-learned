### Sequence Types

| Type | **속성** | **특징** |
| --- | --- | --- |
| list | 가변 |  |
| tuple | 불변 | 개발자가 사용할 일은 없음 |
| range | 불변 |  |
- List
    
    **: “가변”**적인 시퀀스 자료형 (문자열은 불변)
    
    - 리스트 표현법 : []
        - 어떠한 데이터 자료형도 저장 가능 (List안에 List 저장 가능)
- tuple
    
    : 0개 이상의 객체를 포함한 데이터 목록을 저장 (불변)
    
    ※ 리스트와의 차이점 : 가변 vs 불변
    
    - 튜플 표현법 : ()
    - 튜플 사용되는 경우
        
        : 내부 동작과 안전한 데이터 전달에 사용됨 (개발자가 의도적으로 쓰지는 않음)
        
        ※ 튜플이 활용되는 특징 : 다중 할당, 값 교환, 그룹화(언패킹)
        
- range
    
    : 연속된 정수 시퀀스를 생성하는 변경 불가능한 자료형 
    
    - range 표현법 : range(시작 값(n), 끝 값(m), 증가 값=step)
        - n부터 m-1까지 증가
    - 형 변환을 통해서 확인 가

### non-sequence Types

| Type | **속성** | **특징** |
| --- | --- | --- |
| dict | key : 불변, 중복/순서 없음
value : 가변, 중복 가능 | key-value 쌍으로 이루어짐 |
| set | 불변
중복/순서 없음 | 집합 연산 외에는 쓸 일 없음 |
- dict
    
    : **key-value 쌍**으로 이루어진 **순서**와 **중복이 없는 변경 가능**한 자료형
    
    - 딕셔너리 표현법 : {’key’ : ‘value’}
        - key : 변경 불가능한 자료형만 가능 (str, int, float, tuple, range, …)
        - value : 모든 자료형 가능
    - why dict?
        - 데이터를 정의하고 탐색하기 위해서
            
            ※ list는 데이터의 설명을 추가할 수 있고, 선형적 탐색만 가능
            
        - dict는 순서가 없어서 각 데이터의 순서로 정의할 수 없음
        - key는 중복 불가능 (value는 중복 가능)
- set (집합 자료형)
    
    : 순서와 중복이 없는 **변경 가능한** 자료형
    
    - 세트 표현법 : set() ← 빈 세트, {데이터}
    - 집합 연산 가능
        - | : 합집합, - : 차집합, & ; 교집합

### 기타

- None
    
    : 파이썬에서 ‘값이 없음’을 표현하는 자료형
    
    - None 표현법 : = None (’N’ 대문자로)
- Boolean
    
    : 참(True)과 거짓(False)을 표현하는 자료형
    
    - boolean 표혀법 : =True, = False

    - 가변인 친구는 : 각 방에 하나씩 메모리 주소를 모아놓은 집 형식

### 형변환

- 한 데이터 타입을 다른 데이터 타입으로 변환하는 과정
    - 암시적/명시적 형변환
- 암시적 형변환 (파이썬 자체적으로 이루어지는 변환)
    - 정수와 실수의 연산에서 정수가 실수로 변환
    - boolean과 numeric type에서 가능
        - True = 1, False =0
- 명시적 형변환
    - str → int : 형식에 맞는 숫자만 가능
    - int → str : 모두 가능
    - 외울 필요 없음

- 비교 연산자

    - == 비교 연산자
        
        : 엄격한 기준이 아닌 암시적 형변환을 참조하여 결과를 내 줌

    - is 비교 연산자

        - 의도치 않게 False가 나오는 상황 발생
        
        ※ is를 사용할 때 : None을 비교할 때
        
        - 같은 주소에 있는가?
        - None을 비교할 대는 is를 사용하라고 권장
        - 싱글턴 객체 (None, True, False)를 비교할 때
        - 리스트나 객체 비교 시 반드시 ==
