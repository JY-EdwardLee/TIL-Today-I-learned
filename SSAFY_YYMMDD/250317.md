# 분할 정복

## 분할 정복

- 나폴레옹의 분할 정복
- 설계 전략
    1. 분할 : 해결할 문제를 여러 개의 작은 부분으로 나눈다.
    2. 정복  : 나눈 작은 문제를 각각 해결한다.
    3. 통합 : 해결된 해답을 모은다.
- 거듭 제곱 분할 정복
    - C^n = C^n/2 * C^n/2(짝수일 때) or C^(n-1)/2*C^(n-1)/2*C (홀수일 때)
        - 위의 방식으로 나눠서 계산

## 대표적인 분할 정복 알고리즘

### 병합 정렬

- 시간복잡도 : O(nlogn)
    - 분할 할 때 logn, 합칠 때도 logn인데
    - 합칠 때 각 자리의 크기를 N번 비교하기 때문에 nlogn
- 분할 단계
    - 최소 크기의 부분집합이 될 때까지 분할
- 병합 단계
    - 2개의 부분집합을 정렬하면서 하나의 새로운 집합으로 병합

### 퀵 정렬

- 시간 복잡도 : O(nlogn) ※ 최악 : O(n^2)
- 주어진 배열을 두개로 분할, 각각 정렬
    - 나누면서 기준아이템(pivot item) 중심으로 분할
    - 병합 할 필요 없음
- 파티셔닝 (기본 : Hoare 파티션)
    - 피봇을 기준으로 나누는 작업
        - 피봇 선택에 따라 정렬의 성능이 달라진다.
    - 파티션을 고르는 다른 알고리즘
        - Lomuto partition
            - 쉽고 느리다. (최악은 O(n2)으로 동일)
- 최악 시간 복잡도
    - 역순정렬 일 때 or pivot 설정 잘못 했을 때
        - 좌우에 정렬되는 값들이 하나씩만 생김
- why 퀵정렬?
    - 평균 속도가 O(NlogN)으로 빠르다.
    - 특히 대규모의 데이터일 때 효과적으로 동
