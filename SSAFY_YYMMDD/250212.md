### 패턴 매칭

- 고지식한 알고리즘 (Brute Force)
    - 본문 문자열을 처음부터 끝까지 차례대로 순회하면서 패턴 내의 문자들을 일일이 비교하는 방식으로 동작
- 라빈-카프 알고리즘
    - 패턴을 해시값으로 변경
    - 해시값을 비교하여, 동일한 해시값을 가졌다면 직접 패턴 비교
- KMP 알고리즘
    - 불일치가 발생한 텍스트 스트링의 앞 부분에 어떤 문자가 있는지를 미리 알고 있으므로, 불일치가 발생한 앞 부분에 대하여 다시 비교하지 않고 매칭을 수행
    - 패턴을 전처리해 배열 next[M]을 구해 잘못된 시작을 최소화
    - 시간 복잡도 : O(M+N)
- 보이어 무어 알고리즘
    - 오른쪽에서 왼쪽으로 비교
    - 대부분의 상용 소프트웨어에서 채택하고 있는 알고리즘
    - 오른쪽 끝에 있는 문자가 불일치 하고 이 문자가 패턴 내에 존재하지 않는 경우, 이동 거리는 무려 패턴의 길이 만큼이나 된다.
    - 비교 방법
        1. **패턴을 텍스트에 맞춰 배치**
            - 비교할 위치에 패턴을 놓고, 맨 오른쪽 문자부터 비교 시작.
        2. **오른쪽에서 왼쪽으로 문자 비교**
            - 패턴의 마지막 문자부터 차례로 텍스트와 비교해.
            - 모두 일치하면 패턴이 발견된 거야!
        3. **불일치 발생 시 이동 규칙 적용**
            - **배드 캐릭터 규칙**: 틀린 글자가 패턴 안에 있으면, 그 글자의 위치를 기준으로 패턴을 움직여.
            - **굿 서픽스 규칙**: 이미 맞았던 부분(접미사)을 활용해서 최대한 효율적으로 이동해.
        4. **패턴 이동 후 다시 비교**
            - 이동한 위치에서 다시 오른쪽부터 비교를 반복해.
            - 텍스트 끝까지 검사하면 탐색 종료!

### 연습문제

```python
ㄴt = "TTTTTATTAATA"
p = "TTA"

def search(p, t):
    N = len(t)
    M = len(p)

    for i in range(N-M+1):      # t에서 패턴을 비교할 시작 위치 인덱스 (마지막 비교 구간의 시작 위치: N-M+1)
        for j in range(M):          # p에서 비교할 위치 인덱스
            if t[i + j] != p[j]:        # t에 p패턴이 없는지 확인 없으면 break하고 t의 다음 i로 넘어감
                break
        else:                       # break로 탈출하지 않고 loop를 다 순회할 경우 실행
            return i                    # 패턴이 처음 나타난 인덱스 리턴
    return -1

print(search(p, t))

```
