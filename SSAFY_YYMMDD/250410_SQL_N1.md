### Article - User 모델 관계 설정

- Article 모델에 user 외래키 정의
    
    ✅ get_user_model()을 외래키의 모델 인자에 넣을 것 같지만,
    
    settings를 import해서 auth_user_model을 인자에 넣는다.
    
    - 왜 why?
        
        **내부적인 구동 순서**와 **반환 값** 때문에 → 아직 user모델이 정의되기 전이라서
        
        ※ User 모델은 직접 참조하지 않는다
        
        |  | `get_user_model()` | `settings.AUTH_USER_MODEL` |
        | --- | --- | --- |
        | **반환 값** | User Object (객체) | `'accounts.User'` (문자열) |
        | **사용 위치** | *models.py가 아닌 다른 모든 위치* | `models.py` |

### View decorators

※ 데코레이터는 데코레이터가 작성된 순서대로 봅니다.

- Allowed HTTP methods
    - 특정 HTTP method로만 view 함수에 접근할 수 있도록 제한하는 데코레이터
    - 이 method는 실패 reponse로  405를 줍니다.
    1. @require_http_methods([’GET’, ‘POST’…])
        - 배열의 목록에 해당하는 녀석만
    2. @require_safe
        - GET 요청으로 온 녀석만
    3. @require_POST
        - POST 요청으로 온 녀석만

- 데이터베이스 구조를 시각화

- Cardinality
