### str 데이터 구조

- 문자열 조회/탐색 및 검증 메서드
    1. str.find(x)
        - x의 첫번째 위치를 반환 없으면, -1을 반환
        
        ```python
        print('banana'.find('a')) # 1
        print('banana'.find('a')) # -1
        ```
        
    
    1. str.index(x)
        - x의 첫번째 위치를 반환, 없으면 오류 발생
        
        ```python
        print('banana'.index('a')) #1
        print('banana'.index('z')) # ValueError
        ```
        
    
    1. str.isupper() / str.islower()
        - 문자열이 모두 대문자/소문자로 이루어져 있는지 확인
        
        * .is로 시작하는 함수는 boolean으로 return된다.
        
        ```python
        string1 = 'HELLO'
        string2 = 'Hello'
        print(string1.isupper()) # True
        print(string2.isupper()) # False
        print(string1.islower()) # False
        print(string2.islower()) # False
        ```
        
    
    1. str.isalpha()
        - 문자열이 알파벳으로만 이루어져 있는 지 확인
        
        ```python
        string1 = 'Hello'
        string2 = '123heis859381ssh'
        print(string1.isalpha()) # True
        print(string2.isalpha()) # False
        ```

    : 리스트 원본 자체에 영향을 미침 (리스트는 가변임)

    - 리스트 마지막에 항목 x를 추가
2. list.extend(iterable)
    - 리스트에 반복 가능한 객체(iterable)의 모든 항목을 추가 (반복 되는 객체가 아니면 추가 불가능)

    - 리스트의 지정한 인덱스 i위치에 항목 x를 삽입

    - 리스트에서 첫 번째로 일치하는 항목을 삭제

        - 리스트에서 항목 x의 개수를 반환
    3. list.reverse()
        - 리스트의 순서를 역순으로 변경(정렬 x)
    4. list.sort()
        - 원본 리스트를 오름차순으로 정렬
        
        * .sort(reverse = True) ⇒ 내림차순 정렬 (reverse는 키워드 인자임)

## 트랙 복사 및 참고

!주의) 복사 vs 재할당

### 복사

- 가변/불변 객체 개념
    1. Mutable(가변) 객체 : 생성 후 내용을 변경 가능
        
        e.g. list, dict …
        
    2. Immutable(불변) 객체 : 생성 후 내용 변경 불가
        
        e.g. 정수, 실수, 문자열, 튜플 …
        
- 변수 할당의 의미
    - 파이썬에서 변수 할당은 객체에 대한 참조를 생성하는 과정
        - 메모리 주소를 가리키는 Label 역할
- 메모리 참조 방식
    - 변수는 값을 가지는 게 아닌 ‘메모리 주소’를 저장

### 불변/가변 객체의 다른 복사법

- why?
    1. 성능 최적화
        - 불변 객체는 변경이 불가능하므로, 여러 변수가 같은 객체를 안전하게 공유 가능
    2. 메모리 효율성
        - 불변 객체는 동일한 값을 가진 여러 객체가 메모리를 공유할 수 있어 효율적
- 가변 객체의 복사
    
    ```python
    a = [1, 2, 3, 4] # 주소를 할당
    b = a # a의 주소를 b에 할당
    # b를 바꾸면 같은 주소를 바라보기 때문에 a를 출력했 을 대도 바뀜
    print(a is b) # True
    ```
    
- 불변 객체의 복사
    
    ```python
    a = 20 # 20은 고정되어 있는 주소이고 이를 바라보는 주소 할당
    b = a # 20이라는 동일한 주소를 바라보는 새로운 주소 할당
    b = 10 # 10의 주소를 바라보는 새로운 주소 할당
    # b를 바꾸면 a도 바뀌지 않음
    print(a is b) # False
    ```
    

- id() 함수를 사용한 메모리 주소 확인
    
    ```python
    x = [1, 2, 3] # id(x) = 58291
    y = x # id(x) = 58291
    z = [1, 2, 3] # id(x) = 102942
    ```
    

### 얕은 복사

※ 복사란? 서로 영향을 미치지 않도록 같은 값을 가진 새로눈 객체를 복제해 내는 것

- 객체의 최상위 요소만 새로운 메모리에 복사하는 방법, 내부에 중첩된 객체가 있다면 그 객체의 참조만 복사됨
- 구현 방법
    1. 리스트 슬라이싱
    2. copy() 메서드
    3. list() 함수
    
    위 셋 다 동일한 동작을 함
    
- 얕은 복사의 한계
    - 2차원 리스트와 같이 변경 가능한 객체 안에 변경 가능한 객체가 있는 경우
        - a와 b의 주소는 다르지만 내부 객체의 주소는 같기 때문에 함께 변경됨

### 깊은 복사

- 객체의 모든 수준의 요소를 새로운 메모리에 복사하는 방법, 중첩된 메모리까지 모든 새로운 객체로 생성됨
- 구현 방법
    1. deepcopy() 함수 (내장모듈 copy에서 제공)
