# CLI

GUI vs CLI

Directory = 폴더

- Why CLI?
    - 서버마다 모두 GUI가 붙어있지 않기 때문에, GUI가 없이도 서버 관리 가능
    1. 효율성
    2. 정밀한 제어
    3. 표준성
- 테스트 목록
    - ls ⇒ 파일 목록 조회
        
        ㄴ ls + . ⇒ 현재 디렉토리 파일 목록 조회
        
        ㄴ ls + .. ⇒ 상위 디렉토리 파일 목록 조회
        
    - mkdir ⇒ 새 디렉토리 생성
    - touch ⇒ 파일 생성
    - cd  ⇒ Chage directory
    - start  ⇒ 파일/폴더 열기
    - rm ⇒ 파일 삭제
        - ~~rm -rf~~
    - cat ⇒ 내용 보기
    - pwd ⇒ 현재 경로 보기
- 경로
    - 절대 경로
        - 현재 위치와 관계 없이 이동
    - 상대 경로
        - 현재 위치에 상대적으로 이동
